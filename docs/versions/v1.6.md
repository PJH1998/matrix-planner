### 추천 계산 (`src/services/PickupAdvisor.js`)
- **무기**: 배너마다 「전용 무기도 뽑기」(opt.weapon). 켜면 전용 무기 R1, 끄면 기본 무기(`baseWeapon`) = 상시 5성 무기(210X0015) R1.
  서포터는 같은 종류의 4성 공명 효율 무기(부옵 er) R5도 후보로 넣어 0체인 협주력이 가장 높은 것. 상시 5성이 없으면 4성.
  - 미보유: 0체인 + 기본 무기(또는 전용 무기), 비용 95(+70). 보유: 체인 +1(+ 전용 무기, 이미 있으면 그대로). 6체인이면 전용 무기만.
  - `weaponPower`: 전용 무기 선택 옆 수치. 미보유는 0체인 기본 무기 → 전용 무기, 보유는 지금 무기 → 전용 무기의 캐릭터 강도 변화.
- **새로 뽑기(미보유)**: 0체인 + 위 무기, 에코는 체험 세팅.
  - 조합 후보: 고정 조합(TEAM_PRESETS) + 메인 딜러 기준 3인 조합.
    메인 딜러 = X(메인 딜러일 때) 또는 X와 궁합이 있는 메인 딜러 + 개인 피해 상위 보유 메인 딜러 6명.
    나머지 칸 = 메인 딜러의 궁합 표 + 보유 딜러·서포터.
  - 규칙: 메인 딜러 2명은 정석 짝(궁합 1)일 때만, 3명 불가, 서포터 1명까지.
  - 정석 = 고정 조합이거나 메인 딜러와 나머지 딜러(·X가 서포터면 X)의 궁합이 모두 1. 보유로 만들 수 있는 정석 중 강도 상위 8개를 넣어 보고 총점이 가장 오르는 것.
    가장 센 정석이 미보유 공명자를 필요로 하면 「있어야 만들 수 있는 조합」으로 함께 보여 준다.
  - 서브 = 정석이 아닌 보유 조합 중 강도 상위 10개를 넣어 보고 총점이 가장 오르는 것 + (그게 다른 파티를 깨면) 깨지 않는 것 중 가장 좋은 것(총점이 오를 때만).
  - 넣기: 필요한 공명자가 지금 편성에서 배치 횟수(이번 주기 vigor)를 다 쓰고 있으면 그 공명자가 든 파티 중 가장 약한 파티를 포기한다. 새 조합은 포기한 자리(없으면 첫 빈 파티, 없으면 맨 뒤)에.
  - 서브 딜러 빼 오기: 시너지 s(main, x) = 궁합(pairW 양방향 최대) + x가 main에게 주는 반주 이득(outroGain). 새 조합 메인 딜러와의 s가 그 파티 메인 딜러(mainDps)와의 s보다 클 때만 데려오고, 아니면 그 조합은 후보에서 뺀다. 그 파티 메인 딜러가 새 조합 메인 딜러와 같으면(같은 파티를 다시 짜는 것) 비교하지 않는다. 서포터는 비교하지 않는다.
  - 총점 변화(dTotal) = 넣은 편성 총점 − max(지금 편성 총점, 같은 자리에 X 대신 가장 센 보유 공명자를 넣은 편성 총점). dRaw = 넣은 편성 총점 − 지금 편성 총점.
  - 추천 등급: 조합 중 가장 큰 dTotal ÷ 지금 편성 총점 — 6% 이상 강력 추천, 2.5% 추천, 0.8% 고려, 그 아래 보류.
- **돌파(보유)**: 그 공명자 강도만(체인 +1, 전용 무기를 고르면 함께). 딜러 = 개인 피해(characters.damage), 서포터 = 협주력(characters.score).
- 정렬: 새로 뽑기(등급 → 점수) → 돌파(강도 상승 순) → 보류.

## 고려했던 점 / 정한 것
- **첫 설계(버림)**: 지금 편성의 파티마다 한 칸을 X로 바꿔 보기 + 자동 추천을 뽑기 전·후로 돌려 비교. 사용자 피드백으로 바꿨다.
  - 메인 딜러 2명 파티(예: 여우의 별자리·히유키·파수인)가 추천돼 어색했다 → 메인 딜러 2명은 정석 짝만.
  - 사용자 요청 순서: 정석 조합을 채웠을 때 얼마나 오르는지 → 서브 조합 → 그 서브 딜러·서포터를 다른 파티가 쓰고 있으면 어느 파티를 포기해야 하는지.
  - 자동 추천은 욕심쟁이 방식이라 체인 하나로 조합이 크게 흔들려(시그리카 1체인 −1만 점) 뽑기 효과를 재기에 맞지 않았다. 지금은 쓰지 않는다(계산도 빨라짐).
- **돌파는 캐릭터 강도만** (사용자 요청): 보유 공명자의 체인 +1을 편성 총점으로 재면 「편성에 넣는 효과」가 섞이고 파티 계산의 흔들림도 탄다.
- **전용 무기도 캐릭터 강도로**: 처음엔 총점 차이로 쟀는데, 양양·현령처럼 X가 세지면 파티의 메인 딜러 판정이 바뀌어 총점이 오히려 줄기도 했다(4성 → 전용 무기 개인 피해 +36%인데 총점 −). 그래서 강도로 보여 준다.
- **빈 파티 부풀림**: 편성에 빈 파티가 있으면 아무 조합이나 새로 넣어도 총점이 크게 올라(놀던 두 명의 몫) 모두 강력 추천이 됐다(구원 +15%). 같은 자리에 X 대신 다른 보유 공명자를 넣은 경우와 비교해 X의 몫만 센다.
- **정석 서포터**: 강도만으로 고르면 이미 두 파티에서 쓰는 파수인을 데려와 파티를 깨는 정석이 나왔다. 넣었을 때 총점이 가장 오르는 쪽을 고른다.
- 파워 서킷은 전·후 모두 파티마다 가장 좋은 것으로 계산한다(서킷 차이가 뽑기 효과로 잡히지 않게). 그래서 「포기할 파티」의 예상 점수가 배치 화면 숫자와 조금 다를 수 있다.
- **5성 상시 무기 기준** (사용자 요청): 처음엔 4성 무기로 계산했는데, 미보유 수수(4성)와 보유 샤콘(전용 무기)을 비교하게 돼 히유키·루실라·수수가 히유키·루실라·샤콘보다 낮게 나왔다. 기본을 상시 5성으로 올리고, 전용 무기는 배너마다 고르게 했다. 공명 효율이 중요한 서포터는 4성 공명 효율 무기도 허용.
- **서브 딜러는 시너지가 더 클 때만** (사용자 요청): 강도만 보면 산화처럼 다른 파티에서 잘 쓰는 서브 딜러를 빼 오는 조합이 나왔다.
- **배너 카드 → 페이즈 탭 + 가로 배너** (사용자 요청): 처음엔 공명자마다 세로 카드로 모든 정보를 펼쳐 보였는데, 게임의 캐릭터 배너처럼 페이즈를 탭으로 나누고 가로 배너를 눌러 펼치게 바꿨다. 긴 설명 문단은 「읽는 법」 목록으로 줄이고 조합 멤버에 이름을 붙였다.
- 픽업 추천은 이번 주기 보스·파워 서킷 기준 점수다. 다음 주기에는 결과가 달라질 수 있다.

## 1.6.1 (2026-11-23) — 최적 조합 우선
브랜치: `fix/pickup-preset-first`
- 문제(사용자 제보): 수수 미보유일 때 정석에 양양·현령·치사·수수가 먼저 뜨고 히유키·루실라·수수가 빠졌다. 서브에는 카르티시아 조합이 떴다.
  - 원인 1: 정석을 「총점이 가장 오르는 것」으로 골랐다. 히유키·루실라 파티는 이미 샤콘으로 쓰고 있어, 계산상 0체인 수수 ≈ 샤콘이라 거의 안 오르거나 내려갔다.
  - 원인 2: 서브는 궁합과 상관없이 총점으로 골랐다. 수수의 조건부 효과 「이상 효과 스택 +3」이 풍식(카르티시아)에 붙어 카르티시아·샤콘·수수가 높게 나왔다.
- 정석: 최적 조합 2개까지를 보유 여부·총점 변화와 상관없이 맨 앞에. 최적 조합 = 고정 조합(TEAM_PRESETS, 위에 있는 것부터) → 메인 딜러의 기준 파티(공명자 파일 `dpsTeam`, 2명일 때만. X 본인이 메인 딜러인 것 먼저).
  보유로 만들 수 있으면 시너지 비교 없이(force) 넣어 보고, 못 만들면 「있어야 만들 수 있는 조합」. 그다음 총점이 가장 오르는 다른 정석, (정석이 3개 미만이면) 가장 센 미보유 정석.
  - 사용자 요청: 양양·현령의 최적은 양양·현령·치사·수수 — 수수가 없어도 이것을 최적으로 보여 준다. 그래서 고정 조합만이 아니라 기준 파티(dpsTeam)도 최적 조합으로 쓴다.
- 서브: 궁합 있는 조합(메인 딜러 ↔ X, X가 메인이면 X ↔ 나머지 중 하나) 먼저. 없을 때만 나머지에서 고르고 `linked:false`로 「궁합 표에 없는 조합」 표시.
- 추천 등급·예상 총점은 그대로 화면의 조합 중 가장 큰 총점 변화 기준.
- 테스트 가정(사용자 요청): 모든 공명자 보유, 픽업 공명자만 미보유, 예시 편성에서 픽업 공명자가 든 파티는 뺀다(`withoutBanner`). 이 가정에서는 히유키도 픽업이라 수수의 고정 조합은 「있어야 만들 수 있는 조합」으로 나온다.

  - 조화 밀집·파동 메커니즘으로 받던 +50%는 없앴다(사용자 기준: 조화도 파괴).
  - 전 공명자 스킬·체인 확인 결과 파티 누적 효율을 올리는 건 모니에뿐. 다른 방식 둘:
    - 데니아(조화 밀집 모드) 「완전무결」: 조화 밀집 · 이탈을 걸면 부조화 수치 최대치의 50%(2체인 100%)를 한 번에, 같은 목표 300초 1회.
      평균 2중첩 기준 파괴를 반(한) 번 앞당기면 평균 +0.5(+1)중첩 → 누적 효율 +25%(+50%)로 환산(예측치). 사용자 요청으로 반영. 모드별 값이라 불꽃 모드는 0.
    - 청초: 강화 강공격이 부조화 수치를 추가로 쌓지만 수치 미공개, 본인 공격만 → 반영 안 함.
- 시길룸 「항로 이탈」: 전에는 조건 없이 모든 파티 +80%(5중첩 최대치).
  - 「같은 이름의 에코는 1회만」 → 중첩 수 = 이름이 다른 에코 어빌리티 수. 공명자 1명당 자기 에코 1 + `echoExtra`(스킬이 에코 어빌리티 발동으로 간주).
  - encore.moe에서 「에코 어빌리티를 발동한 것으로 간주」 문구가 있는 공명자: 프롤로바·칸타렐라·로코코·구원 → 1(추정, 같은 스킬 여러 번이 다른 이름으로 셈인지 불명), 루실라 에코 모드 → 4(「망각마다 서로 다른 이름의 에코 어빌리티로 간주」).
  - 보스 효과 `stack:{per:10,max:5,full:30}`. 보통 파티 3중첩 +30%, 프롤로바·칸타렐라 + 아무나 5중첩 +80%.
  - 같은 메인 에코를 두 명이 끼는 경우는 세지 않는다(에코 이름까지 보지 않음).
- 유리 표시: 조건 키 `tuneBreak`·`echoAlt`(conds.js `by`: 공명자 파일 수치가 0보다 크면 만족).

## 1.6.3 (2026-11-23) — 파티별 숙련도
브랜치: `feat/team-skill`
- 사용자 요청(제보): 파티별로 숙련도를 설정하고 싶다.
- 파티 객체에 `skill`(top·good·normal)을 선택 필드로 둔다. 없으면 전체 숙련도(`state.skill`)를 따른다. state-schema는 세 값만 남기고, 없으면 필드를 만들지 않는다(공명 모드 `modes`와 같은 방식).
- `TeamCalculator.skillOf(team)` → `skillMul(team)` → `partyDamage(score, team)`. `simulate`가 파티마다 넘긴다. 강도(teamScore)는 그대로이고 보스 피해·예상 점수에만 들어간다.
- UI: 파티 칸 강화 효과 select 옆에 숙련도 select. 첫 칸 「기본 (전체 값)」. 직접 고르면 금색 테두리(`.tskill.fixed`).
- 자동 추천·픽업 추천이 새로 만드는 파티는 `skill`이 없어 전체 숙련도를 따른다. 파티 순서를 바꾸면 숙련도도 파티와 함께 움직인다(공명자만 드래그로 옮기면 숙련도는 칸에 남음).
- 같은 버전에서 숙련도 단계를 넷으로: 장인(top ×1) · 숙련(skilled ×0.9) · 보통(good ×0.8) · 뉴비(normal ×0.65).
  - 사용자 요청: 100%(실측 기준)를 「장인」으로 올리고 90% 정도를 「숙련」으로.
  - 저장 키는 그대로 두고 이름만 바꿨다. top = 장인, 0.9 단계는 새 키 skilled. 전에 숙련(top)을 고른 사용자는 장인으로 이어진다. 기본값도 top(장인) 그대로.
  - 예시 편성 예상 총점 비율(참고): 숙련도 피해 배율과 거의 같지만, 약할수록 앞 라운드(점수 배율 낮음)에 머물고 처치 보너스를 놓쳐 조금 더 낮게 나온다.
- 2R 점수 배율 1.1 → 1.15.
  - 사용자 제보. 3.5 공식 패치 노트(kurogames 뉴스 5091, 역경 선봉 S2 규칙): Round 1 ×1.00 · Round 2 ×1.15 · Round 3 ×1.25. 이전 값 1.1은 출처 없이 「게임 표기」로 적혀 있었다.
