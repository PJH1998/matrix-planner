# v1.2 — 파티 자동 추천 · 체험 세팅 (2026-11-16)

포함: 1.2 ~ 1.2.7

## 패치 내역
### 1.2
- 파티 자동 추천: 정석 조합(예: 히유키·루실라·수수) 먼저 → 정석 메인+서브 짝에 서포터 → 나머지는 궁합 표 + 파티 강도로 센 파티부터
- 다른 딜러의 정석 파트너를 빼앗는 조합은 뒤로, 어울리는 조합이 없으면 메인 딜러도 남김, 예상 점수 1000점 미만 파티 제외
- 배치 횟수·방랑자 1명 규칙 준수, 강화 효과·순서 자동, 서포터는 항상 3번 칸, 2인 파티는 만들지 않음
- 서포터 배분 뒤 파티끼리 서포터를 맞바꿔 전체가 세지면 교체
- 미리보기 → 「적용」을 눌러야 저장, 「되돌리기」는 추천 전 처음 편성으로
- 순서 정렬 기본값: 약한 파티부터. 상성으로 확실히 이득일 때만 강한 파티를 앞으로
- 체험 세팅: 육성 안 한 공명자를 매트릭스 기본 세팅(90레벨·상시 무기 R1·스킬 8레벨·약한 에코)으로 계산

### 1.2.1 ~ 1.2.7
- 1.2.1 라운드별 보스 HP·점수 배율 재보정, 강한 파티 피해 과대 완화 (보스 HP·점수 배율은 예측치)
- 1.2.2 서포터 조건부 효과(`supCond`): 수수·릴리·모니에·복령·감심. 파티 카드에 「수수 → 양양·현령 +15%」식 표시
- 1.2.3 우클릭 → 원하는 칸 눌러 편성(드래그 안 되는 환경 대응)
- 1.2.4 피해 보너스 일부만 입력 시 빈 칸을 기준치(속성 60 · 주력 유형 30)로 채움
- 1.2.5 보유 캐릭터 기본 정렬 출시순, 피해 보너스 기준치 표시
- 1.2.6 공명자별 이잘키 기준 스탯(공격력·HP·크리·크피·3코 구성), 무기 기본 스탯·부옵 반영
- 1.2.7 드래그 편성을 포인터 이벤트로 직접 처리, 우클릭을 pointerdown에서 처리

## 고려했던 점
- 자동 추천은 "점수 최대화"보다 **사람이 납득하는 조합**이 먼저. 그래서 정석 조합·정석 짝을 강도 계산보다 앞에 둠.
- 추천은 사용자의 편성을 덮어쓰므로 **미리보기 + 적용 + 되돌리기**가 필수.
- 순서를 너무 자주 바꾸면 뒤섞여 보임 → 확실한 이득일 때만 바꿈.
- 드래그·우클릭 문제는 브라우저 확장 프로그램(드래그 차단·우클릭 허용) 때문. 기본 이벤트 대신 포인터 이벤트로 직접 처리.
