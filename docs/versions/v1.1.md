# v1.1 — 명조 스타일 리뉴얼 · 육성 투자 효율 · 주기별 기록 (2026-11-16)

포함: 1.1, 1.1.1

## 패치 내역
### 1.1
- 명조 스타일 리뉴얼: 다크 모드 기본, 금색 강조, 모서리 장식 패널, 정사각형 초상화 + 이름 띠 카드(4성 보라 띠), 속성 색 배경, 게임 속성 아이콘 필터
- 보유 캐릭터 페이지: 큰 카드 목록, 우클릭 보유 전환, 프로필 창(레벨·공명 체인·무기·재련)
- 무기 115종, 공명자별 무기 성능(전용 무기 차이)을 강도에 반영
- 스탯 입력: 게임 스탯 화면 캡처 Ctrl+V 자동 인식, 피해 보너스는 공명자별 필요한 칸만
- 보스 진행 예측·예상 점수·예상 총점, 숙련도 설정, 강화 효과 추천, 보스 유리/불리 표시
- 육성 투자 효율 탭(참고용): 체인 +1·무기·재련 +1의 예상 총점 변화, 10연차당 효율
- 주기별 기록 탭, 매트릭스 남은 시간, 정렬(5성 먼저·강함순·이름순), 업데이트 탭
- 피해 유형 강화를 피해 비중만큼만 반영, 신규 공명자 릴리

### 1.1.1 (강도·예상 점수 계산 개선)
- 반주 버프를 피해 비중(일반 공격·강공격·공명 스킬·해방·에코) × 버프 %로 수치화. 교대 순서 A→B→C→A, 파티 전체 버프는 모두에게
- 서포터 없는 파티에서 반주 이득을 못 받는 공명자는 비중을 낮춤
- 서브 딜러를 메인 딜러와 같은 기준으로 평가(서브끼리 비교하던 문제 수정), 구원 → 서브 딜러
- 합일 대응 피해 증가는 합일 공명자 본인에게만, 합일 공명자 2명 이상일 때만
- 예상 점수를 준 피해량에 비례하도록 수정, 라운드 점수 배율 재조정
- 방랑자는 속성과 관계없이 1명만, 금희 협동 공격 메커니즘(파트너 없으면 감산, 추정치)
- 숙련도: 숙련 / 보통 / 뉴비 (보통·뉴비 배율은 추정치)

## 고려했던 점
- 게임 화면과 비슷한 분위기로 맞춰 처음 보는 사람도 익숙하게. 속성은 색만으로도 구분되게.
- 투자 효율은 **참고용**으로 표기. 유료 투자(체인·무기)를 권하는 것처럼 보이지 않게.
- 보스 진행은 실제 플레이 기록으로 보정하되, **업데이트 노트에는 실측 수치를 적지 않는다**(이 원칙이 이때 생김).
- 점수는 보스 HP 비율이 아니라 준 피해에 비례해야 라운드가 오를수록 점수가 맞게 커진다.
- "효과가 누구에게 붙는가"(합일 +55%가 파티 전체로 새던 문제)를 처음 겪음 → 이후 효과 범위 규칙으로 발전(1.3 이후 참고).
