# v1.0 — 첫 공개 (2026-11-04)

## 패치 내역
- 파티 배치, 보유 공명자·성장도 관리, 이번 주기 보스·파워 서킷 정보
- 브라우저 자동 저장(localStorage)과 JSON 백업, 다크 모드, 공명자 초상화 60장
- 시너지 표시: 초상화 마우스 오버로 반주 스킬·메커니즘, 파티 안 시너지 연결(✓)·추천 조합(★)
- 파티 강도: 공명자별 기본 체급 + 공명 체인별 상승률(Prydwen 계산 기준), 서포터 딜증·시너지·파워 서킷 반영
- 추천 순서 정렬: 보스 진행을 시뮬레이션해 저항 보스를 피함. 파티마다 예상 상대 보스 표시
- 초상화를 누르면 첫 번째 빈 칸에 배치

## 고려했던 점
- **로그인 없는 정적 사이트.** 서버·빌드 도구 없이 GitHub Pages에 올린다. 데이터는 브라우저에만 저장하고, 기기 이동은 JSON 백업으로 해결.
- 강도의 기준은 외부 공개 계산(Prydwen)의 체급·체인 상승률. 개인 세팅은 아직 반영하지 않음(1.1 스탯 입력, 1.3 에코 세팅으로 이어짐).
- 순서 정렬은 "센 파티 먼저"가 아니라 보스 상성(저항)을 피하는 쪽을 목표로 함.
