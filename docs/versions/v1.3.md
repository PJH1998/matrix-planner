# v1.3 — 에코 세팅 · 세트 효과 반영 (2026-11-17 ~ 11-19)

포함: 1.3 ~ 1.3.3, 그리고 1.3.3 뒤 업데이트 노트 없이 들어간 수정(3.8 주기, 보스 효과, 유지율)

## 패치 내역
### 1.3 (11-17)
- 에코 세팅: 칸마다 캡처 붙여넣기 / 여러 장 끌어다 놓기 → 코스트·주옵·부옵 인식(OCR), 헷갈린 숫자는 수치 단계·코스트별 최대치로 자동 보정
- 에코로 최종 스탯 계산(기본 + 무기 + 노드 + 에코 + 세트 2세트·조건부 효과×유지율), 에코가 스탯 직접 입력보다 우선
- 공식 공략 사이트 추천 스탯과 비교, 공명 효율 부족 시 경고(강도엔 미반영)
- 파티 세트 효과(떠오르는 구름 등)는 주력 세트 대비 차이만큼만
- 보유 캐릭터 프로필 보기(전신 그림), 즐겨찾기 하트, 캐릭터 설정 창 재배치
- 공명자 데이터를 공명자별 파일(`data/chars/<id>.js`)로 분리, 중개자(CharDB·BossDB·EchoDB) 도입

### 1.3.1 (11-18) 비전투 최종 스탯
- 스탯 배율 기준을 비전투 캐릭터 정보창(무기 부옵·비전투 상시 패시브 포함)으로. 전투 중 조건부 효과는 이잘키 비교에서 제외
- 서포터 유효 부옵을 캐릭터별로(HP·방어력 비례, 공효는 최소치까지만, 크리 제외)
- 릴리 공효 연동 버프, 에코 빈칸 선택과 파일 열기 분리

### 1.3.2 (11-18) 서포터 지원 기준
- 모니에·수수·파수인 공효 연동 버프, 브렌트 공효 → 공격력
- 서포터 10명의 지원 기준(HP·방어력·공효·공격력 중 필요한 것), 체인·세트에 따른 공효 기준 변화
- 서포터 기본 무기 = 전용 무기 또는 지원 추천 무기, 근거 없는 무기 효율은 추정하지 않음

### 1.3.3 (11-18) 강도 계산 개편: 공명력 · 협주력
- 딜러 = 공명력(최종 스탯 피해 기대값 ÷ 이잘키 기준 × 100), 서포터 = 협주력(주는 버프 ÷ 기준 세팅 버프 × 100)
- 상시 체인 스탯을 최종 스탯에 포함, 에코 미입력 공명자는 체험 세팅(공식 가이드 추천 스탯, `data/trial.js`)
- 파티 강도 = 딜러 한 바퀴 피해 합 ÷ (한 바퀴 시간 합 + 서포터 1명당 7초). Prydwen DPS 안의 파티원 버프는 뺌
- 계산 기준 탭, 로고 옆 버전 표시
- 설계 문서: [docs/strength-v2.md](../strength-v2.md)

### 노트 없이 들어간 수정 (11-19)
- 3.8 주기(4페이즈) 보스·파워 서킷·긴급 공명자 반영, 3.7 주기 데이터 보관
- 보스 효과를 보스 진행 계산에 반영, 효과 적용 범위 정리, 모드 공명자 유리 표시
- 효과 유지율(`up`), 실드 유지율(파티 실드 공명자 기준), 릴리 에코 메커니즘 제거

## 고려했던 점
- **OCR은 브라우저 안에서만**(tesseract.js). 이미지를 밖으로 보내지 않는다. 여러 전처리 패스 다수결, 수치는 게임 단계로 스냅, 코스트는 고정 스탯으로 추정.
- **공명 효율 최소치 우선순위**: 이잘키 `er` → 공식 가이드 `guide.er` → 역할 기준치(120/125/200). 모자라면 **경고만** — "에코를 갈아라"가 아니라 사이클이 꼬인다는 뜻으로 표기.
- 비교 기준을 게임 비전투 정보창으로 맞춘 이유: 사용자가 게임 화면과 직접 대조할 수 있어야 함.
- 리팩터링 전 특성 테스트(`tests/calculation-characterization.test.mjs`)를 먼저 고정 → 구조 분리 중 값이 바뀌면 버그.
- 1.3.1에서 서포터 반주 버프의 체인 배율이 빠진 걸 아무도 몰랐던 일이 1.3.3 개편(딜러·서포터 분리)의 계기.
- **효과 범위 규칙**(11-19 서리 효과 피해 +80%가 파티 전체로 새던 버그 뒤): 모든 효과를 "적 디버프·파티 버프 = 전원" / "조건 맞는 공명자 본인만"으로 구분. 효과 문구의 주어를 보고 조건 키를 고른다.
